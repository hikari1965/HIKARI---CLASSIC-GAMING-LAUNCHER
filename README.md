# HIKARI---CLASSIC-GAMING-LAUNCHER
HIKARI is an all-in-one solution for retro gaming on MacOS, for plataforms running MacOS Monterey and intel Macs. The App will handles light emulation cores, emulators and ROM/SAVES management, Pokemon transfer data between saves, Classic gamepads support, gaming session history and offer UI customization

Features already implemented on first public build:
- Add your you banners and covers for games
- Dualshock4, Xbox one and Series wireless controller, generic bluetooth and usb suppor
- Link with PKHeX for MacOS, you can open or send SAVE files directly from the HUB for you preferred Pokemon save editor (optimized for PKHeX)
- Link with stand alone emulators
- Legacy plataforms and favorites categories tab
- Lightwheight UI, for fast navigation of the user

Features to come:
- Internal Swift base alternative to Pokemon save editing and pokemon storage and transfer between games
- Classic and Legacy bluetooth console gamepads support
- Wii-U gamepad support
- DS, GBA, GBC and GB local core emulation, as Wii-U gamepad support for those plataforms

This is being coded with the help of free AI tools like Qwen and Gemini, and Free Claude for code revision. The interface and HUD designs are being created by the author of the project, you can see his digital and painting works at instagram @shit_poets_society.
